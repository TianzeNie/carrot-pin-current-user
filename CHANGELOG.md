# Changelog

## 1.3.0-pinme.1

Based on Carrot, But Userscript 1.3.0.

### Added
- Automatic detection of the logged-in Codeforces handle.
- Pinned current-user row sourced from Friends Standings.
- Prediction rendering on the pinned row.
- Conditional standings reconstruction when public standings omit the pinned contestant.
- Reconstructed overall-rank display for the pinned row when available.

### Changed
- Fork metadata uses repository-local update/download URLs instead of upstream release URLs.
- Removed the previously hard-coded `Nekkko` handle.
